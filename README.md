# Olive & Ember -- Restaurant Landing Page

A single-page, responsive site for a fictional restaurant. Pure HTML/CSS/JS, no build step, no dependencies.

## Sections

Hero, menu highlights, our story, hours & location, and a reservation form (front-end only -- wire the `onsubmit` handler in `index.html` up to a real reservation system to make it functional).

## Running it

```bash
npx serve .
```

## Deploying

Works as-is on GitHub Pages, Netlify, Vercel, or any static host. For GitHub Pages: repo Settings -> Pages -> Deploy from branch -> `master` / root.
